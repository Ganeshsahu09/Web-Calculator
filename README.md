# Web Calculator

## Description
A simple calculator built using HTML, CSS, and JavaScript. The application performs basic arithmetic operations and demonstrates DOM manipulation.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Clear Function
- Responsive Design

## Technologies Used
- HTML
- CSS
- JavaScript

## Concepts Used
- DOM Manipulation
- Event Handling
- Functions
- User Input Processing

## How to Run
1. Download the project.
2. Open index.html in a browser.
3. Start using the calculator.
